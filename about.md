## What this is

The Destiny Agent Grimoire is a fan-made, non-commercial project. It has three
parts:

<ul class="tile-grid">
  <li><strong>A local library</strong><p>Destiny lore you can search and quote-check.</p></li>
  <li><strong>An optional AI connection</strong><p>Lets an AI app look things up in the library.</p></li>
  <li><strong>Characters</strong><p>Read the same library and answer in their own voice.</p></li>
</ul>

You can use any part on its own. The library is useful without a character. The AI
connection is useful without a character too. The characters are for when you want
someone to talk to, not just a search box.

## Why it exists

Destiny lore is spread across books, transcripts, item text and old grimoire
cards. Looking things up is slow, and it is easy to repeat a line that sounds
right but is not real.

This project keeps one searchable copy and one quote policy. The library records
where each entry came from. The built-in checker tells you whether a line is
official text. The characters use the same library, so they have something to
check against instead of guessing.

The code, tests and documentation are MIT licensed. Destiny, its text, characters
and art belong to Bungie. This project is not affiliated with or endorsed by
Bungie.

## Accessibility

The site aims to be readable and usable without a mouse:

- clear page regions, a skip link and keyboard-friendly navigation;
- visible focus outlines and full keyboard access to menus and collapsible
  sections;
- colours chosen for contrast in both themes;
- reduced motion respected through the system preference;
- stable, linkable headings;
- tables and code blocks that remain readable on narrow screens.

If something is difficult to read or operate, open an issue with the page and the
assistive technology or browser you used.
